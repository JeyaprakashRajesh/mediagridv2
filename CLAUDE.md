# MediaGrid — guide for Claude Code

Windows ⇄ iPhone ecosystem. Read `README.md` for the full architecture and API table.

## Layout
- `windows/src-tauri/src/` — Rust backend (Tauri 2 + axum on :47800): `lib.rs` setup/commands, `server.rs` routes, `state.rs` shared state, `library.rs` scanning/thumbnails, `control.rs` input/screen, `clip.rs` clipboard, `config.rs` config/auth.
- `windows/ui/` — desktop front-end, plain HTML/CSS/JS (no bundler). Talks to Rust via `invoke` and to the same HTTP API as the phone.
- `ios/` — SwiftUI app (iOS 26+, Liquid Glass) generated by XcodeGen from `project.yml`. `Core/` = logic, `UI/` = views, `Shared/` = compiled into app AND widget, `Widgets/` = Dynamic Island.
- `.github/workflows/build.yml` — builds IPA (macOS) + Windows installer; artifacts land on the `builds` branch.

## Commands
- Rust check/build: `cd windows/src-tauri && cargo check` / `cargo build`
- Run backend without UI: `MEDIAGRID_HEADLESS=1 windows/src-tauri/target/debug/mediagrid` (or `scripts/dev-server.sh` with sample media)
- API smoke test: `scripts/api-smoke.sh`
- JS syntax check: `node -e "new Function(require('fs').readFileSync('windows/ui/app.js','utf8'))"`
- Desktop dev (Windows only): `cd windows && npm install && npx tauri dev`
- iOS: no local Mac — push to `main`, then `gh run list -R JeyaprakashRajesh/mediagridv2 -L 1` and `gh run view <id> --log-failed | grep " error: "`
- Fetch builds: `git clone --depth 1 -b builds https://github.com/JeyaprakashRajesh/mediagridv2 builds`

## Rules
- Keep the API backward compatible: add fields/routes, don't rename. Update the API table in README.md when routes change.
- Rust: never hold a `parking_lot` lock across `.await` (handlers must be `Send`). Windows-only code goes behind `#[cfg(target_os = "windows")]` with a stub so Linux `cargo check` passes. No `unwrap()` on I/O in handlers.
- New Tauri plugin ⇒ add its permission to `windows/src-tauri/capabilities/default.json`.
- Swift: language mode 5; stores are `@MainActor ObservableObject` singletons injected as environment objects; wrap UIKit/AVFoundation callbacks in `MainActor.assumeIsolated`; no third-party packages; use system glass APIs and `Theme` colors.
- Anything touching Live Activity types must stay in `ios/Shared/` (shared by both targets).
- Verify before finishing: `cargo build` passes, JS syntax check passes, and for iOS changes the CI `ios` job is green.
- Commit messages: imperative summary + short bullet body.
